# ReproducibleRProject

<!-- badges: start -->
<!-- badges: end -->

A template for a reproducible research project using Singularity, R, and
C++, with package dependency management in R based on renv.

## Development

Enter the development environment and run the project tasks:

```console
devenv shell
devenv tasks run project:install
devenv tasks run project:test
```

Run `devenv tasks list` to see all available tasks.
