## Development

Enter the development environment and run the project tasks:

```console
devenv shell
devenv tasks run project:check
```

Run `devenv tasks list` to see all available tasks.

Build the documentation with `devenv tasks run project:docs`. To preview it and
rebuild it when sources change, run:

```console
devenv up docs
```
